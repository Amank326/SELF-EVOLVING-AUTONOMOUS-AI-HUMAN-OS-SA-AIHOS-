## 🔄 How It Works

### Real-Time Example: Decision Making

```
1. AI Reasoning Engine creates decision
   └─ Options: [send_reminder, do_nothing, suggest_break]
   └─ Confidence: 0.85 (85%)
   └─ Complexity: Medium (3 options)

2. AIStateBroadcaster detects event
   └─ Sets cognitiveState = THINKING
   └─ Extracts metrics:
      - decisionConfidence = 0.85
      - decisionComplexity = 0.6
      - cognitiveLoad = 0.7

3. AIMotionController computes parameters
   └─ breathingRate = 1.0 + (0.7 × 0.5) = 1.35 Hz
   └─ rotationSpeed = 0.4 × (1 + 0.6 × 0.8) = 0.59×
   └─ colorTheme = CYAN (analytical)
   └─ glowIntensity = 0.8 × 0.85 = 0.68
   └─ particleEmissionRate = 1.0 × 1.2 = 1.2

4. Broadcaster sends AIMotionState JSON
   └─ Via WebView bridge to JavaScript

5. ProceduralAnimationController receives
   └─ Converts to animation targets
   └─ Next 60 frames: compute animation values

6. Each frame (60 FPS):
   └─ breathing = sin(phase) × 0.1 + 1.0
   └─ rotation.y += velocity.y × deltaTime
   └─ color = lerp(old_color, CYAN, 0.5)
   └─ Return animation frame

7. AIResponsiveComponentManager applies
   └─ mesh.scale = breathingValue
   └─ mesh.rotation = (x, y, z)
   └─ mesh.material.color = cyan
   └─ mesh.material.emissiveIntensity = 0.68
   └─ particles.emissionRate = 12/frame
   └─ particles.orbitRadius = 1.2

8. Three.js Renders
   └─ User sees: Bright cyan core
   └─ Breathing at 1.35 Hz
   └─ Rotating at 0.59× speed
   └─ Orbital particles
   └─ Glow/bloom effect
   
Visual Result: "AI is confidently thinking"
```

## ✨ Key Innovations

### 1. **No Keyframe Animation**
Traditional systems use pre-recorded sequences. This system computes animations live based on AI state.

### 2. **State-Driven Visuals**
Every visual change has a direct, meaningful correspondence to AI activity. Users can "read" AI state from the animation.

### 3. **Procedural Computation**
Six animation parameters are computed procedurally:
- Breathing: sinusoidal oscillation
- Rotation: per-axis velocity accumulation
- Color: smooth RGB interpolation
- Glow: material + bloom pass
- Particles: behavior-pattern driven
- Morphing: vertex deformation

### 4. **Real-Time Integration**
Latency from AI event to visual change is ~50-100ms - imperceptible to humans.

### 5. **Smooth Transitions**
Exponential smoothing (factor 0.2) prevents jitter while maintaining responsiveness.

### 6. **Extensible Design**
New states, behaviors, and effects can be added without modifying core logic.
