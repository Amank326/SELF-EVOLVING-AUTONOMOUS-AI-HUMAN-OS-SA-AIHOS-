# Quick Start Guide

Get started with SA-AIHOS in 5 minutes!

## 1. Prerequisites ✓

Make sure you have:
- [ ] Android Studio (latest version)
- [ ] Android device or emulator (API 26+)
- [ ] Basic understanding of Android apps

## 2. Installation 📱

### Option A: Clone and Build
```bash
git clone https://github.com/Amank326/SELF-EVOLVING-AUTONOMOUS-AI-HUMAN-OS-SA-AIHOS-.git
cd SELF-EVOLVING-AUTONOMOUS-AI-HUMAN-OS-SA-AIHOS-
```

Open in Android Studio:
1. File → Open
2. Select the project folder
3. Wait for Gradle sync
4. Click Run ▶

### Option B: Download Release (Coming Soon)
- Download APK from Releases page
- Install on Android device
- Grant necessary permissions

## 3. First Run 🚀

When you first launch the app:

1. **AI Initializes**
   - Status changes to "Active"
   - Evolution Stage: 1
   - Autonomy Level: 0.3
   - Ready to learn!

2. **Check System Status**
   - Look at the AI Status Card
   - See current metrics
   - Observe AI mode (Idle)

## 4. Your First Interactions 💬

### Store Your First Memory
1. Tap **"Memory"** button
2. Enter: "I love morning coffee"
3. Tap **"Confirm"**
4. ✅ Memory stored!

Check the logs to see: `[TIME] Memory stored: I love morning coffee...`

### Perform Your First Reasoning
1. Tap **"Reason"** button
2. Enter: "What do I like in the morning?"
3. Tap **"Confirm"**
4. Watch AI process the query:
   - Retrieves relevant memories
   - Performs inference steps
   - Generates conclusion
5. ✅ See result in logs!

### Trigger Self-Reflection
1. Tap **"Reflect"** button
2. AI analyzes its performance
3. Generates insights
4. Suggests improvements
5. ✅ Check logs for insights!

### Evolve Your AI
1. Tap **"Evolve"** button
2. AI triggers evolution cycle
3. Capabilities increase
4. ✅ Watch metrics improve!

### Schedule Autonomous Tasks
1. Tap **"Schedule"** button
2. Enter: "Daily reflection"
3. Tap **"Confirm"**
4. ✅ Task added to queue!

### Execute Tasks
1. Tap **"Execute"** button
2. AI runs pending tasks
3. Records outcomes
4. ✅ Learns from results!

## 5. Understanding the Interface 📊

### AI Status Card

```
┌─────────────────────────────────┐
│   AI System Status              │
│                                 │
│   Status: Active  Mode: Idle   │
│                                 │
│   Memory:     [████░░░░░░] 40% │
│   Processing: [██░░░░░░░░] 20% │
│   Autonomy:   [███░░░░░░░] 30% │
│                                 │
│   Evolution: Stage 1            │
└─────────────────────────────────┘
```

- **Status**: Active/Inactive
- **Mode**: Current AI activity
- **Memory**: Memory utilization %
- **Processing**: Current load %
- **Autonomy**: Independence level %
- **Evolution**: Growth stage

### Control Buttons

- 🧠 **Memory**: Store information
- 🎯 **Reason**: Ask questions
- 🔄 **Reflect**: Self-analysis
- ⚡ **Evolve**: Force evolution
- 📅 **Schedule**: Plan tasks
- ▶️ **Execute**: Run tasks

### System Logs

Real-time activity feed showing:
- Memory operations
- Reasoning processes
- Reflection insights
- Evolution milestones
- Task executions

## 8. Troubleshooting 🔧

### App won't launch
- Check Min SDK (API 26+)
- Clear cache and rebuild
- Check Logcat for errors

### Gradle sync fails
```bash
./gradlew clean
./gradlew build --refresh-dependencies
```

### UI not responding
- Check device resources
- Restart app
- Clear app data

### Database errors
- App will auto-recover
- Uses fallbackToDestructiveMigration
- Data will be reset if needed

## 9. Privacy & Data 🔒
