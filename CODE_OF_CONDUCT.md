## Our Commitment

We are committed to providing a welcoming, inclusive, and respectful environment for all contributors, maintainers, and community members, regardless of:

- Age
- Body size
- Visible or invisible disability
- Ethnicity
- Sex characteristics
- Gender identity and expression
- Level of experience
- Education
- Socio-economic status
- Nationality
- Personal appearance
- Race
- Caste
- Color
- Religion
- Sexual identity and orientation

We pledge to act and interact in ways that contribute to an open, welcoming, diverse, inclusive, and healthy community.

---

## Our Standards

### Examples of Behavior That Contributes to a Positive Environment

- Demonstrating empathy and kindness toward others
- Being respectful of differing opinions, viewpoints, and experiences
- Giving and gracefully accepting constructive feedback
- Acknowledging mistakes, apologizing, and learning from them
- Focusing on the community's best interests, not just personal gain
- Using welcoming and inclusive language

### Examples of Unacceptable Behavior

- Harassment, intimidation, or threats of any kind
- Discriminatory comments or jokes
- Personal attacks, insults, or derogatory language
- Unwanted romantic or sexual attention or advances
- Publishing others' private information without consent
- Deliberate misgendering or use of incorrect names
- Condescending tone or gatekeeping behavior
- Spam, marketing, or self-promotion without context
- Trolling, bad faith arguments, or deliberate disruption
- Other conduct that would be reasonably considered inappropriate

## Enforcement

### Reporting Violations

If you witness or experience a violation of this Code of Conduct, please report it by:

1. **Email**: Contact the project maintainers directly
2. **Private issues**: Use GitHub to report privately to maintainers
3. **Trust & Safety contacts**: (Listed in project leadership, if appointed)

**What to include in your report:**
- Description of the violation
- When and where it occurred
- Who was involved (if comfortable sharing)
- Any relevant evidence (messages, links, etc.)
- Your contact information (optional)

### Investigation & Response

All reports will be:

- **Taken seriously**: We treat all reports as credible
- **Investigated promptly**: Typically within 1-2 weeks
- **Kept confidential**: Details shared only with those who need to know
- **Handled fairly**: Both reporter and reported person have opportunity to share perspective
- **Resolved appropriately**: Response proportional to violation severity

### Consequences

Depending on severity and history, violations may result in:

1. **Private warning**: First-time minor violations
2. **Formal warning**: Continued or moderate violations
3. **Temporary suspension**: Serious or repeated violations
4. **Permanent ban**: Extreme or pattern violations
5. **Reporting to authorities**: If illegal activity occurs

All decisions are documented and appeals are possible.

## Specific Guidance

### Technical Discussions

We value spirited technical debate. Here's how to do it respectfully:

**✅ Good:**
```
"I see why you chose approach A, but I think approach B would 
be better because of X performance benefit. Let me show you 
a benchmark..."
```

**❌ Bad:**
```
"That approach is stupid. Anyone with a clue would use 
approach B instead."
```

### Code Review

Code review can feel personal. Remember:

**✅ Good:**
```
"This function is doing multiple things. Could we split it 
into separate functions? That would improve readability."
```

**❌ Bad:**
```
"This code is a mess. You clearly don't understand software design."
```

### Feedback on Work

Whether it's code, docs, or design:

**✅ Good:**
```
"Great start! I think this would be even clearer if we added 
examples. Would you like help with that?"
```

**❌ Bad:**
```
"This is incomplete. Why would you submit something like this?"
```

### Responding to Criticism

If someone critiques your work:

**✅ Good:**
```
"Thanks for the feedback. I see your point about performance.
Can I ask how you'd approach it differently?"
```

**❌ Bad:**
```
"That's just your opinion. My way works fine."
```

## Inclusivity

### Language

We're an international community. Keep language:

- **Clear**: Avoid idioms, slang, or cultural references that don't translate
- **Accessible**: Explain technical concepts as if for someone new to the field
- **Respectful**: Honor different English proficiency levels

### Visibility

We value contributions from people of all backgrounds. If you don't see yourself represented:

- **Speak up**: Tell us how we can be more inclusive
- **Contribute**: Help us build a more diverse community
- **Suggest resources**: Point us to diversity initiatives

### Accessibility

We aim to make participation accessible to all:

- **Issues**: Provide context and background
- **Video**: Include transcripts
- **Images**: Describe with alt text
- **Code**: Comment clearly for readability
- **Events**: Offer accommodations if needed

---

## Conflict Resolution

If you have a conflict with another community member:

1. **Talk directly** (if safe): "I felt hurt by what you said. Can we talk?"
2. **Involve mediator** (if needed): Ask a maintainer to help facilitate
3. **Escalate** (if unresolved): Report through official channels

We believe most conflicts can be resolved through respectful dialogue.
