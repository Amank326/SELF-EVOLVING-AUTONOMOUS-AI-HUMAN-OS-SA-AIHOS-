```

│  ├─ Reasoning → Filter options, adjust confidence         │
│  ├─ Reflection → Modulate learning depth                  │
│  ├─ Evolution → Gate learning types, control aggressiveness
│  └─ Autonomy → Orchestrate decisions                      │
│                                                            │
│  Output Layer: Visual Feedback                            │
│  ├─ Filament 3D Rendering                                 │
│  ├─ Material Properties (roughness, metallic)             │
│  ├─ Lighting (intensity, color temperature)               │
```

## 📈 Environmental Influence

### How AI Adapts to Environment

| Scenario | Reasoning | Reflection | Evolution | Visuals |
|----------|-----------|-----------|-----------|---------|
| **Critical Battery** | Minimal options, low confidence | Skipped/throttled | PATTERN_LEARNING only | Dim, fast, rough |
| **No Network** | Local actions only | Uncertain | Offline-safe types | Muted colors |
| **Night Time** | Careful exploration | Dream-like patterns | Gentle learning | Warm/orange tones |
| **High Activity** | Reactive decisions | Minimal | No learning | Bright, energetic |
| **Optimal Learning** | Full exploration | Frequent, deep | All types allowed | Bright, smooth |
